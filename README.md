# VeriEdu

Verilog 入门可视化学习平台的公开发布页。这里只有编译后的网页和安装包。

| | 地址 |
|---|---|
| 在线打开 | https://fifcggff.github.io/veriedu-release/ |
| 下载安装包 | https://github.com/fifcggff/veriedu-release/releases/latest |

- `veriedu-web-*.zip`：网页静态包。解压到网站根目录，或在该目录运行 `npx serve`。
- `veriedu-vscode-*.vsix`：在 VS Code / Cursor 里用「Install from VSIX」安装。

在线版可以上课、做练习、看 3D 电路板和波形，学习进度保存在本机浏览器。评论、邮箱登录和进度云同步需要自行部署后端。
